# Lucas Lydio - Portfolio

Portfolio for Lucas Lydio, a Full Stack Software Engineer with experience delivering enterprise web applications, REST APIs, integrations, and production support for systems used by more than 3,000 people.

## Profile represented on the site

- Full Stack Developer at the Brazilian Air Force since May 2024
- Technical Support Specialist at the Brazilian Air Force from January 2021 to May 2024
- Angular, Node.js, TypeScript, PostgreSQL, Docker, CI/CD, and production troubleshooting
- B.Sc. Software Engineering at UniEVANGELICA, final semester

## Local development

```bash
npm install
npm run dev
```

Eleventy serves the site at `http://localhost:8080/` by default.

## Production build

```bash
npm run build
```

The generated site is written to `dist/`.
